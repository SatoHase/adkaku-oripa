## 0. 何が「アドアフィぽくない」のか

| 観点 | 現状 | 参考サイト | 対応 |
|---|---|---|---|
| 一覧の形 | 1カラムの横長カード、テキスト主体 | **2カラムのサムネイルグリッド** | グリッド化（§3） |
| 視線の中心 | 価格と保証の数字が横並び | **カード上部の大きなビジュアル** | 数値サムネを自作（§4） |
| CTA | 詳細ページにしか無い | **カードごとにオレンジの大ボタン** | カードにCTA（§5・要判断） |
| 緊急性 | 「残りわずか」バッジのみ | 左上に赤リボン、締切表示 | NEW／残口バッジ（§4.3） |
| 回遊導線 | テキストリンク2本 | ジャンルタイル・チップ・FAB | §6・§7 |
| 情報の信頼付け | なし | 「全1101件」「最終更新 9/11 14:00」 | §8 |
| 配色 | 白＋青のみ（SaaS的） | 白＋**オレンジCTA＋赤バッジ＋緑/青のピル** | §1 |

要するに **「読み物のレイアウト」から「商品棚のレイアウト」へ変える**。

```css
  --surface: 210 14% 97%;          /* #F7F8F9 サムネ枠の下地 */

  /* ブランド（CLAUDE.md 準拠・変更しない） */
  --primary: 230 76% 50%;          /* #1E3EE0 ロゴ・リンク・見出しバー */
  --primary-foreground: 0 0% 100%;

  /* アクション色（新規） */
  --cta: 27 88% 52%;               /* #F08017 送客ボタン専用 */
  --cta-shadow: 27 90% 40%;        /* #C4620A 下に 0 3px 0 のベタ影 */
  --danger: 0 75% 48%;             /* #D61F1F 緊急バッジ */
  --success: 158 76% 30%;          /* #12885A サイト種別ピル・アド額 */

  --radius: 12px;                  /* カード */
  --radius-btn: 10px;              /* ボタン */
  --radius-pill: 999px;
```

- フォント: `-apple-system, system-ui, "Hiragino Sans", "Noto Sans JP", "Yu Gothic", sans-serif`（**Inter は外す**。日本語まとめサイトらしさが出ない）
- ウェイト: 見出し **800** / カードタイトル **700** / 本文 400
- 本文 `font-size: 16px` / `line-height: 1.6`
- ダークモードは維持するが、CTAオレンジと赤バッジは両モードで同値（明度だけ +6%）

## 4. 数値サムネ `src/components/OripaThumb.astro`（新規・最重要）

参考サイトはパック画像が主役だが、**当サイトは事業者バナーを転載しない方針**（法務要件）。画像枠を空けるとグリッドが死ぬので、**アド額を見せる自作サムネ**で埋める。

- 枠: `aspect-ratio: 4/3`（≒125px）、`background: #F7F8F9`
- 中央: `+300円`（26px / 800 / `--success`）、その下に `103.0%`（11px / #666）
- 背景: `site_id` から決定論的に色相を算出した淡いグラデ（`hue = [...site_id].reduce((a,c)=>a+c.charCodeAt(0),0) % 360`）
  → **サイトが増えても定義追加不要**。site_id のハードコードは禁止。
- アド額が大きいほど彩度を上げる（0円=無彩色、+1,000円以上=最大）

将来 `banner_url` が JSON に追加されたら、このコンポーネント内だけを `<img>` に差し替えれば済むよう、**他のどこにも画像ロジックを書かない**。

### 4.3 バッジのルール（`ends_at` が空なので時間ではなく在庫と鮮度で出す）

| 条件 | 表示 | 色 |
|---|---|---|
| `first_seen_at` が24時間以内 | `NEW` | 赤 #D61F1F |
| 残口比率 ≤ 15% | `残りわずか` | 赤 #D61F1F |
| 上記以外 | 出さない | — |

同時該当時は「残りわずか」を優先（1カードにバッジは1つまで）。

## 5. 【要判断】カードのCTAをどこへ送るか

| 案 | 内容 | 効果 | 副作用 |
|---|---|---|---|
| **A（推奨）** | カードのオレンジボタン＝**事業者へ直接送客**（`rel="sponsored nofollow noopener"`、文言に「PR」）。下の「詳細をみる」が自サイト詳細へ | 参考サイトと同じ。CVRが最も高い | 詳細ページのPVが落ちる |
| B | オレンジボタン＝詳細ページへ。送客は詳細でのみ | 現行の導線を維持、SEO資産が育つ | 1クリック挟むぶんCVRが下がる |

**A を推奨**。ただし送客リンクを一覧に出す以上、§8 のPR表記を一覧の直上にも必ず置くこと。
終了（`status === "ended"`）のカードは **どちらの案でもCTAを出さない**（グレーの「提供終了」表示に置換）。

## 11. 実装結果（2026-09-11 反映済み）

§1〜§10 を実装済み。`npm run build` 通過（データあり／空／未生成の3パターン）。1ページ ≒ 9.5KB gzip。
§5 は **A案（カードのオレンジボタンから直接送客）** を採用。

指示書から変えた点:

| 箇所 | 指示 | 実装 | 理由 |
|---|---|---|---|
| §2 ヘッダー | ロゴ中央寄せ | 左ロゴ＋右ナビ（高さ57px・白・下線は指示通り） | 375pxで中央ロゴと固定ナビが衝突するため |
| §3 グリッド | 3カラムは720px以上 | **560px以上**で3カラム | 720pxだと2カラムが間延びし、参考サイトの169px幅から離れるため |
| §7 シート | チップごとにシート | 共通のシート1枚を開き、押したチップの項目までスクロール | コード量とUXの一貫性。FABも同じシートを開く |

実装時に踏んだ不具合（再発注意）:

- `.ocard { display:flex }` が UA の `[hidden]{display:none}` に勝ち、絞り込みが効かなくなる。`[hidden]{display:none !important}` を先頭に置くこと
- `<fieldset>` の既定ボーダーがシート内に出る。`border:0; min-inline-size:0` を当てる（`legend` に `float` は不要）
- `.ocard__frame` は `<a>` なのでサムネ内の数字に下線が出る。`text-decoration:none` が必要

## 12. カードのビジュアル（2026-09-12 決定・実装済み）

事業者のバナー画像は使わない方針を維持したまま、`OripaThumb.astro` を**カテゴリ別サムネ**に強化した。

### 権利関係の整理（判断の前提）

| 素材 | 現時点 | 見通し |
|---|---|---|
| オリパ個別のバナー絵柄 | 使わない | 事業者との個別許諾が要る。ASP素材には通常含まれない |
| 事業者のロゴ・公式バナー | 使わない | **A8提携の承認後に利用条件を確認**。素材として配布されていれば利用可 |
| 自作ビジュアル | 使用中 | 制約なし |

補足: `banner_url` は `sites/dokkan-toreca.yml` で既に抽出され vision の入力に使われているが、`lib/sheet.mjs` の `COLUMNS` に無いため保存されていない。将来使うなら列を追加するだけでよい（フロントは `OripaThumb.astro` 内だけの差し替えで済む設計）。

### 実装した内容

- **オリパ名からカテゴリを判定**（`detectCategory()`）。`site_id` ではなく名前の正規表現なので、サイトが増えても定義追加は不要
  - ポケカ / ワンピ / 遊戯王 / デュエマ / ドラゴンボール / MTG。未判定は従来どおり `site_id` 由来の色相にフォールバック
- カテゴリごとに**色相**を割り当て、イラスト・背景グラデーション・右上のテキストラベルに反映
- **自作イラスト（SVG）**: 扇状に広がるトレカ3枚＋キラ。カテゴリ色で塗り分ける
- **ジャンルアイコン**: 中央のカードの絵柄部分に、カテゴリごとの自作ラインアイコン（24x24）を描く
- 彩度はアド額に連動（0円＝くすんだ色 → +1,000円以上＝最大）
- 画像下部に**数値帯**（`アド額 +2,000円 / 110.0%`）。参考サイトの「画像＋その上のバッジ」構造に合わせ、サイト名ピルは画像上からカード本文へ移した

### ジャンルアイコンの置き換え表（重要）

参考サイト（cardchusen.com）は各IPの意匠をそのままアイコンにしているが、**当サイトでは使わない**。一般的な題材に置き換えている。

| カテゴリ | 参考サイト | 判断 | 当サイトのアイコン | 置き換えの根拠 |
|---|---|---|---|---|
| ポケカ | モンスターボール | 不可（著作物・立体商標） | 稲妻 | ありふれた記号 |
| ワンピ | 麦わら帽子（赤リボン） | 不可寄り（ルフィの帽子の翻案と見られうる） | 錨 | 航海具の一般名詞 |
| 遊戯王 | ミレニアム・パズル | 不可（著作物） | ピラミッド | 実在の建造物。ホルスの目・吊り環は付けない |
| ドラゴンボール | 星入りオレンジ球 | 不可（著作物） | 星 | 幾何形状 |
| デュエマ | カード裏面 | 不可（複製） | クリスタル | 幾何形状 |
| MTG | マナ・シンボル | 不可（意匠） | 五角形 | 幾何形状 |

**IPのロゴ・キャラクター画像・固有の意匠は一切使わない。** アイコンはジャンルの雰囲気を出す役割に徹し、「どのIPか」の識別はテキストラベル（記述的使用）が担う。アイコンのパスは `src/lib/oripa.ts` の `ICONS` にまとめてあるので、差し替えはそこだけで済む。

### A8バナー素材の扱い（2026-09-12 時点：保留）

DOPA・どっかんトレカ・エクストレカのA8バナー素材をカードのサムネに使う案を検討したが、**一旦見送り**。自作イラストを継続する。

見送りの理由:

1. **素材はサイト単位で、オリパ単位ではない** — 1社1枚しかないため、同じサイトのカードが全部同じ絵になり、一覧の識別性が落ちる
2. **カード幅167pxでは文字が潰れる** — 素材は600×500等で面積の大半が訴求文。3.6倍の縮小で判読不能になる
3. **煽り表現がサイトの方針と衝突する** — 「神引き続出!!」「爆アド」「還元率101%超」は、数値で淡々と見せる編集方針（§5 / CLAUDE.md）と矛盾する。広告主の表現なのでPR表記があれば違法ではないが、トーンが壊れる

将来使う場合の置き場所候補（サムネではなくサイト単位の枠として）:

- 詳細ページの送客ボタン付近に1枚（送客直前で最も効く。1ページ1枚なので軽い）
- 一覧のインフィード枠（カード8枚ごとに1枠）
- サイトタイルの下に横スクロールで3社分

実装上の注意: A8の素材は `<img>` ＋計測用1×1ピクセルのHTMLで提供され、**タグは改変せずそのまま貼る**必要がある（切り抜き・加色は規約違反になりやすい。`loading="lazy"` の追加も改変にあたる）。サイズ調整はCSS側で行う。素材タグは `site/src/data/ad-materials.ts` に `site_id` キーのマップで持ち、**未登録の `site_id` は枠ごと出さない**設計にすれば、サイトが増えても壊れない。

なお素材にはピカチュウ・リーリエ等のIPが含まれるが、これは広告主が権利処理した前提の配布素材であり当サイトの責任範囲ではない。ただし権利者対応で素材が差し替わる可能性はある（ホットリンクなので自動追従する）。

## 13. 一覧の仕様変更（2026-09-12）

| 変更 | 内容 |
|---|---|
| 見出し | ヘッダー直下の「アド確オリパまとめ」の表示を廃止。SEO/支援技術向けに `visually-hidden` の `<h1>` だけ残す |
| 事業者ロゴ | サイトタイルのマークを、各社の公開ロゴに差し替え（出所は `docs/logo-sources.md`） |
| 終了したオリパ | `<details>` で折りたたみ。既定は閉じた状態 |
| 追加読み込み | 開催中の一覧を初期20件表示。「もっと見る（残りN件）」で20件ずつ追加。絞り込み・並び替えを変えると20件に戻る |

実装メモ:

- ロゴは `SITE_LOGOS`（`src/lib/oripa.ts`）のマップ。**未登録の `site_id` は頭文字マークにフォールバック**するので、サイトが増えても壊れない
- ロゴ下地はライト／ダークとも**白のまま**にする。DOPAのロゴが黒一色のため、ダークで下地を暗くすると消える
- ロゴ画像の `max-height` は**百分率ではなく px** で止める（グリッド／フレックス配下で百分率が効かない環境がある）
- 追加読み込みはクライアント側。全カードはHTMLに出力済みで `hidden` で出し分けるだけなので、クローラは全件を見られる

### 事業者ロゴの扱い

§12 で「事業者のバナー画像は使わない」としたが、**ロゴは別扱い**とする。各社を識別する目的での商標の使用（指名的使用）であり、比較・ディレクトリ系メディアでは一般的な運用。バナー（広告クリエイティブ）の転載とは性質が異なる。

- 取得元・取得日は `docs/logo-sources.md` に記録する
- 縮小と再エンコードのみ。加筆・改変はしない
- 事業者から削除・差し替えの申し出があれば、`SITE_LOGOS` から外すだけで頭文字マークに戻る

## 14. PR表記の位置（2026-09-12 変更）

ヘッダー上の灰色帯（`.pr-bar`「本サイトはプロモーション（アフィリエイト広告）を含みます。」）を廃止した。

**表記自体は残す。** ステマ規制（景表法の指定告示）対応で全ページに必要なため、小さな一行として出す。

```
※当ページにはアフィリエイト広告（PR）が含まれます。   ← 12px / 右寄せ / muted
```

文言は `src/components/PrNote.astro` に集約し、既定では `Base.astro` が `<main>` 冒頭に出す。**位置を変えたいページだけ** `Base` に `prNote={false}` を渡し、任意の場所で `<PrNote />` を置く。既定を「出す」側にしてあるので、ページを増やしても置き忘れない。

| ページ | 位置 |
|---|---|
| トップ | サイトタイルの下・絞り込みの上（参考サイトと同じ位置。`prNote={false}` ＋ 自前配置） |
| 詳細・固定ページ | 本文冒頭（既定） |

- フッターの「本サイトはアフィリエイトプログラムを利用しており…」はそのまま維持

帯ごと完全に削除すると、詳細ページ（送客リンクのある本命ページ）でフッターまで開示が無くなり、開示の明瞭性が問われうる。位置は変えてよいが、**各ページの冒頭に出す**という条件は維持すること。

## 15. ファーストビュー（2026-09-12 追加）

トップページのヘッダー直下に、全幅のヒーローバナーを入れた。

- 画像: `site/public/hero-750.webp` / `hero-1440.webp`（原版は `docs/hero-source.png`、2070×760 PNG 1.7MB）
- 原版をそのまま置くと重すぎるので、**WebPで2サイズに書き出して `srcset` で出し分ける**（750w=45KB / 1440w=118KB）
- `sizes="(min-width: 720px) 720px, 100vw"`。コンテナ幅が720pxなので、それ以上は拡大しない
- LCP対策として `fetchpriority="high"`、`width`/`height` を実寸で指定してCLSを防ぐ
- `Base.astro` に `<slot name="hero" />` を用意し、**トップページだけが埋める**。詳細・固定ページには出ない
- PR表記はヒーローの下（`<main>` 冒頭）。ファーストビュー内に収まるので開示の明瞭性は保たれる

画像を差し替えるときは、原版を `docs/hero-source.png` に置いて同じ2サイズを書き出すこと。

```python
from PIL import Image
im = Image.open("docs/hero-source.png").convert("RGB")
for w in (750, 1440):
    im.resize((w, round(im.height * w / im.width)), Image.LANCZOS) \
      .save(f"site/public/hero-{w}.webp", "WEBP", quality=84, method=6)
```

